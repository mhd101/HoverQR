# HoverQR – Instantly Scan & Generate

🚀 **HoverQR** is a lightweight Chrome extension that lets you **scan and generate QR codes instantly by hovering**—no clicks, no phone, no hassle.

This repository contains the **landing page source code** for **https://hoverqr.in**.

---

## ✨ What is HoverQR?

HoverQR makes working with QR codes fast and effortless:

- 🔍 Scan QR codes instantly by hovering over images or links  
- ⚡ Generate QR codes for URLs or selected text  
- 🖱️ No clicking required  
- 🔒 Privacy-first (no tracking, no unnecessary data collection)  
- 🧩 Lightweight and fast Chrome extension  

The landing page explains the product, features, and pricing.
